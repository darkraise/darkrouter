Unit rule

44 · Unit rule — 10px --legend, no space, so the value keeps its optical weight.

value + var(--legend) unit, no space

142ms 1.2k $0.0021 26.4k/1.9k

same values, unit undifferentiated (wrong)

142ms 1.2k $0.0021 26.4k/1.9k

A trailing unit gets the 10px --legend treatment, shrunk so it does not steal optical weight from the digits. A leading currency symbol does not shrink — it is part of the number, set at the value's own size and weight, because a prefix does not compete with the digits the way a suffix does.

22 · Termination rule — below the served row the spine drops to --hairline-subtle and marks go hollow-5px at 45% opacity. Spec §4.

Ranks 04–08 were never attempted — the router stopped at rank 03. Their marks shrink to a 5px hollow square in --hairline-subtle, the spine beneath them drops to the same dim token, and their text sits at 45% opacity. The right margin carries a latency bar scaled to the ladder's own maximum (rank 02's 30,000ms timeout), which is why rank 01's 412ms failure and rank 03's 1,847ms serve both read as a thin sliver — the timeout, not a clock, sets the scale.

Two-digit zero-padded ordinals, 11px mono, --legend, right-aligned — "01" occupies the same optical width as "10" would, so the gutter never re-flows once a ladder grows past nine candidates. A 3px tick reaches from every rank into the spine's approach; every fifth rank (05, 10, …) draws a 5px tick instead, giving the eye a count without reading a single digit.

Reason format

55 · Reason format — machine_code · plain sentence. The code is what you grep for, the sentence is what you read.

model_not_offered target does not serve claude-sonnet-4-6
cooling 4m 12s remaining
no_capability vision demanded, model has none
context 210k requested, 200k available
no_credential no key configured for this provider
adapter_surface darkrouter's bedrock adapter cannot speak rerank

Every skip and every failure resolves to this one shape — a stable machine_code in mono ink, a hand-readable sentence in sans --ink-muted. The code is what a log query filters on; the sentence is what an operator reads without opening a runbook.
