Health / decision split

22 · Health/decision split — state colours are provider identity, --trace is router verdict. Spec §3.1. Amber appears only as a health pip and a cooling skip mark.

Left: three provider identity pips — what each provider IS, from --state-healthy / --state-cooling / --state-failed. Right: the router's verdict on the same request — what it DECIDED, in --trace and --bezel. A healthy provider (groq) can still be skipped; a cooling one (cerebras) can still serve. State colour never appears in the gutter; --trace never appears on a pip. A third, narrower use of --state-failed exists alongside these two: the DESTRUCTIVE AFFORDANCE on a control whose action removes something (a delete button's border and hover text) rather than reporting an outcome that already happened. It is defensible precisely because a destructive click produces a failed-shaped result — the row is gone — but it is a third, named thing, not a variant reading of a request's status or a provider's health, and it never appears on a pip or a ladder mark.

Unit rule

44 · Unit rule — 10px --legend, no space, so the value keeps its optical weight.

same values, unit undifferentiated (wrong)

A trailing unit gets the 10px --legend treatment, shrunk so it does not steal optical weight from the digits. A leading currency symbol does not shrink — it is part of the number, set at the value's own size and weight, because a prefix does not compete with the digits the way a suffix does.

Reason format

55 · Reason format — machine_code · plain sentence. The code is what you grep for, the sentence is what you read.

model_not_offered target does not serve claude-sonnet-4-6
cooling 4m 12s remaining
no_capability vision demanded, model has none
context 210k requested, 200k available
no_credential no key configured for this provider
adapter_surface darkrouter's bedrock adapter cannot speak rerank

Every skip and every failure resolves to this one shape — a stable machine_code in mono ink, a hand-readable sentence in sans --ink-muted. The code is what a log query filters on; the sentence is what an operator reads without opening a runbook.

    The rows, tiles or axes the well will fill with, drawn unmistakably inert: a dashed border where a live one is solid, a diagonal hatch, no state colour anywhere on it, and field names in place of values so there is no value to misread.
