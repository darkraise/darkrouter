  1. 1

    A legend sentence, in Sans

    Sans, because a person is explaining rather than the wire reporting. It names what the well holds when it holds something, not merely that it is empty. Never an exclamation, never an illustration.

  2. 2

    A dimmed specimen of the real content

    The rows, tiles or axes the well will fill with, drawn unmistakably inert: a dashed border where a live one is solid, a diagonal hatch, no state colour anywhere on it, and field names in place of values so there is no value to misread. A reader must never be able to count a specimen as a real provider, request or row.

  3. 3

    At most one action

    One, and only where a single obvious next step exists — here, clearing the filters. Zero is the right number when nothing the operator can do from this well would change the outcome, which is why the trace's Bodies panel offers none.
