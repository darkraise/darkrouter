Unlocked — a deliberate two-variable run

The switch is off, so the panes no longer mirror. Two parameters have diverged and the comparison now carries three variables, not one. The footer keeps reporting — the numbers are still true — but a slower, dearer right pane no longer tells the operator anything about claude-opus-4-20250514 on its own. The divergence is marked in bezel and legend, not in a state colour and not in trace: it is a fact about this bench, not an outcome and not a router decision.
