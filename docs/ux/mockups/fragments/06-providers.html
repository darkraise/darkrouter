The middle case is the one the product cannot show today. A listing that has failed for six hours renders exactly like one refreshed three minutes ago, because nothing in the admin package reads the discovery table — so the operator finds out when a model that was retired this morning is still being routed to this afternoon.

https://bedrock-runtime.eu-central-1.amazonaws.com required unless a preset supplies it

bearer · x-api-key · api-key · query-param · none · sigv4 · gcp-sa · oauth

priority

20 walked high to low; lands under vertex at 30

enabled

created enabled unless the body says otherwise

region

eu-central-1 signs every sigv4 request; bedrock only

project

vertex only patchable, unlike location

location

vertex only create-only — changing it moves every catalogued model to a different endpoint, which is a new provider
