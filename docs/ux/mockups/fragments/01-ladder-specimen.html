Mode 3 — compressed (models catalog)

The same vocabulary at catalog density: rank, a 10px mark, provider id, nothing else. Eight rows read as a barcode of sigils — the shape of the fleet at a glance, without a single word. The router expands one candidate per (provider, credential, model), so a provider with a second configured key earns a second row — ranks 05–08 repeat the same four providers for exactly that reason, each marked key 2 in --legend beside the id.

Every mark is hollow, and that is the mode's whole claim. This is a catalog reading of what the router WOULD do, not a record of what it did: nothing here has been sent, so nothing here is filled. Cerebras carries the cooling mark in both its rows because cooling is a fact about the provider that is true right now, which a prediction is entitled to show; a filled mark would assert an attempt that never happened. Fill is the one thing that separates this from the trace, and the trace is the only mode allowed to use it.

Two-digit zero-padded ordinals, 11px mono, --legend, right-aligned — "01" occupies the same optical width as "10" would, so the gutter never re-flows once a ladder grows past nine candidates. A 3px tick reaches from every rank into the spine's approach; every fifth rank (05, 10, …) draws a 5px tick instead, giving the eye a count without reading a single digit.

Reason format

66 · Reason format — machine_code · plain sentence. The code is what you grep for, the sentence is what you read.

model_not_offered target does not serve claude-sonnet-4-6
cooling 4m 12s remaining
no_capability vision demanded, model has none
context 210k requested, 200k available
no_credential no key configured for this provider
adapter_surface darkrouter's bedrock adapter cannot speak rerank

Every skip and every failure resolves to this one shape — a stable machine_code in mono ink, a hand-readable sentence in sans --ink-muted. The code is what a log query filters on; the sentence is what an operator reads without opening a runbook.
