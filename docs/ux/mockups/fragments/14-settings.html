Catalog

33 · Sync now → POST /api/catalog/sync. Discovery enabled is a pointer in the schema so an explicit false is distinguishable from absent.

catalog models.dev restart last sync 2026-08-24 02:11:07 · 8 configured providers matched · 1,412 catalogue entries rebuilt

Fetches models.dev immediately and rebuilds the snapshot without waiting for the interval. It is the button an operator wants after adding a provider whose models the catalog has never seen, and it does not exist today.

discovery 4 values restart 8 of 8 providers listed within their interval
enabled restart

This switch governs the only outbound traffic the gateway starts on the operator's behalf: a listing call to every enabled provider, on every enabled credential, on a timer, whether or not a request is in flight. Turning it off today means editing darkrouter.yaml and restarting the process — there is no endpoint behind this control, and an operator on a metered or audited network has no way to stop those calls from the console.

The field is a pointer in the schema rather than a bool, so an explicit false in the file is distinguishable from a key that was never written — which is what lets the default stay on without silently overriding an operator who turned it off.

The TTL slides: every authenticated request pushes the expiry out another 30 days, so the tab left open on a laptop three weeks ago is still a live session and stays live for as long as that tab keeps polling. Nothing in the product lists them and nothing revokes one — the only way to invalidate a session today is to restart the process. The third row is a phone on a public address that has not been touched in a fortnight, which is exactly the row this region exists to make visible.

Appearance

55 · Two axes. The seventeen-axis switcher is removed: an ops console reading live health must not let a gradient picker change what amber means.

appearance 2 axes live stored in this browser, not on the server — two operators can hold two different answers
mode live
system light dark
follows the operating system until an operator picks one. Light is not a palette swap of dark: the recessed well inverts from darker-than-panel to brighter-than-panel, so the reading stays the highest-contrast thing in the frame either way.
density live
compact cozy
compact is the 30px row this console is drawn at. Cozy relaxes rows and controls to 36px and changes nothing else — no type scale, no colour, no spacing rhythm.

Two axes, and no third. A settings screen that offers an accent picker, a font choice and seven density steps is negotiable chrome; this console is an instrument reading live provider health, and an operator must not be able to change what amber means on the screen where amber is the warning. Mode and density are the only two choices that cannot break a reading.

warnings 3 · a warning does not stop a reload

line 41

providers[3].api_key is set in the file. That provider was imported on first run and its credential lives encrypted in SQLite; the file value is read by nothing and should be removed before the file is shared.

line 88

aliases.vision targets openrouter/qwen-2.5-vl-72b, which no enabled provider serves. The alias resolves to nothing until openrouter is enabled — a dangling target is a warning, never a validation error.

line 103

policy.retry.cooldown_base is 800ms, below the 1s floor the breaker enforces. The ladder uses 1s, and this value has had no effect since the policy block was imported anyway.

Re-reads the file, re-validates it, and re-applies only the blocks the file still governs. A reload that fails to parse changes nothing — the previous configuration keeps serving, which is why this button is safe to press on a production gateway.

what the file still governs server, log, capture, catalog and discovery are read from the file on every start and on every reload. providers, aliases and policy are not: each was imported once on first run and lives in SQLite from then on, so editing them in the file has no effect — exactly as editing providers: already has none today. Round-tripping YAML would destroy the operator's own comments, and an overlay where the file is the base and the database wins would give one value two sources of truth and no way to see which is in effect. The marker in the gutter above is how a value says which of the two it is, and GET /api/config cannot answer that question today.
