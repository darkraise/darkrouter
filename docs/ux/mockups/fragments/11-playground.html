The number is the provider's own whenever the served candidate's kind matches the inbound dialect — an anthropic candidate answering an anthropic request is counted by anthropic, and a gemini pair by countTokens. Every other pairing, this one included, is counted locally with a BPE tokenizer, so the response carries X-Darkrouter-Estimated and the readout carries the approximation sign. A local estimate is not an error and not a warning: it stays in the neutral register, marked but not coloured.
